## Estructura
- `python/`: versión en Python (validaciones, cadenas, búsqueda, reportes)
- `csharp/`: versión en C# (terminal)

## Cómo ejecutar
- Python: `python python/Codigo_Python.py`
- C#: `dotnet run` dentro de la carpeta `csharp/`

## Funcionalidades
- Validación de DNI y teléfono
- Registro y búsqueda de trámites
- Ordenamiento y reportes


## Organización y validación de expedientes

Antes de registrar un expediente, el sistema verifica que los datos ingresados cumplan con las validaciones correspondientes.

La información se almacena mediante arreglos paralelos, en los que cada posición contiene los datos relacionados con un mismo expediente.

## Beneficios del sistema

- Reduce errores al ingresar información.
- Facilita la búsqueda de expedientes registrados.
- Permite mantener los datos organizados.
- Ayuda a consultar y generar reportes de los trámites.
